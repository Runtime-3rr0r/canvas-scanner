# Homework Pre-Submit Checklist

Pre-submission diagnostic: score the student's written work against the assignment's rubric buckets. A diagnosis, never a grade, and never a ghostwriter.

## When to Use
- "Check my homework before I submit", "will I lose points for X", "did I miss anything"

## Procedure
1. **Rubric**: extract from the assignment sheet via vision_analyze, or read Submission Norms from the course COURSE-BRAIN (format, naming, units/sig-figs expectations, late policy). If the rubric is unknown, mark buckets as unknown rather than guessing.
2. **Read the work** (photos/PDF/AI-guide-adjacent files).
3. **Per-problem checklist** against buckets: correct answer ✅ / work shown ✅ / units 🟡 / sig figs 🟡 / format+naming ❌ — one row per problem.
4. **Aggregate patterns**: "strong on correctness and work-shown; units missed on 3 of 7; sig-fig rounding slips on numbers < 1."
5. **File** `<HW-name>-PreSubmit-Checklist.md` beside the work (auditable — the instructor can see what was flagged).
6. **Repeated patterns** → auto-add a drill block to the Roadmap before the next assignment in that course.

## Pitfalls
- Never rewrite or ghostwrite answers — flags only.
- A clean checklist is not a guarantee; state that scoring is the instructor's call.
- If the rubric bucket is ambiguous, say so and move on (don't fabricate a rule).
